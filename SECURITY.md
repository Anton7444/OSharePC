# Security Policy

## Reporting a vulnerability

Please do not post sensitive vulnerability details publicly before maintainers have had an opportunity to review them. Contact the maintainer privately through the project owner's available GitHub contact method. If GitHub Private Vulnerability Reporting is enabled for this repository, use that channel.

Include the affected version, Windows version, reproduction steps, and any relevant redacted logs. Do not include passwords, private keys, access tokens, or personal files.

## Supported versions

The latest published release is the currently supported release. Older releases may not receive security fixes.
